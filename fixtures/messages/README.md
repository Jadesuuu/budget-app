# SMS / notification fixtures

Redacted copies of real messages (reference numbers scrambled, names and last-4 digits replaced). Wording,
amounts, dates and format are kept as received, because the parsers depend on them.

`sender` is the SMS sender ID as it appears on the phone. "GCash" and "BPI" are assumed until confirmed on a
real phone; the Phone capture page lists the sender of every captured message, so a mismatch is visible there.
