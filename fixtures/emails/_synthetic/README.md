# Synthetic fixtures

These emails are **made up** to test the email pipeline (forward unwrapping, Gmail confirmation,
sender checks, account matching). `testbank.example` is not a real bank and these are **not** real
bank templates. Real templates live in `fixtures/emails/<institution>/` and are redacted copies of
actual emails.

The Gmail confirmation fixture follows the commonly seen format; replace it with a redacted real one
once forwarding is set up.
